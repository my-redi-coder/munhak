# 직접 올리는 파일

코드에 넣지 않고 사용자가 직접 깃허브에 올리는 파일들이에요. 파일 이름이 정확해야 해요.

| 파일 | 어디에 쓰여요 | 없으면 |
|---|---|---|
| `events/homer-bgm.mp3` | 최정 홈런 배경음 (직접 찍은 육성응원) | 배경음 없이 진행 |
| `songs/song2.mp3` | 8회말 여난부두 응원 음원 (응원가 2번을 같이 씀, `config.js`의 `EV_BGM.yeonan`) | 음원 없이 48초 동안 진행 |
| `events/yeonan-lyrics.json` | 여난부두 노래방 가사 (가사 싱크 도구로 만든 것) | 가사 없이 진행 |
| `songs/song*.mp3` + `songs/songs.js` | 응원하기 때 랜덤 응원가 | 기본 비트 |

- 이벤트 음원을 다른 파일로 바꾸려면 `js/core/config.js`의 `EV_BGM` 한 줄에서 파일 경로만 바꿔요.
- 가사 파일은 가사 싱크 도구의 '내보내기' 내용을 그대로 붙여 넣은 텍스트 파일이에요. 메모장으로 저장할 땐 파일 형식 '모든 파일', 인코딩 UTF-8.
- 깃허브 웹: 저장소에서 `events` 폴더로 들어가 **Add file → Upload files**(파일 올리기) 또는 **Create new file**(가사처럼 붙여 넣기) → **Commit changes**.
