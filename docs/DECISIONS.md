# 기획과 결정 사항

## 한 줄

비시즌에 들어가 다음 시즌의 열기를 상상하는 1루 관중석. 분위기는 활기찬 봄날 야구장.

## 산사에서 직접 확인한 것 (2026-10-30, 사이트 소스 분석)

- 정체성 문구: "말없이 같이 앉아 있는 온라인 절". 모든 문구가 이 톤(해요체, 짧게).
- 로딩: 미색 배경(#eeece3), 작은 아이콘, "산사", "법당을 여는 중", 숨 쉬는 점.
- 3인칭 시점. 바닥을 누르면 걷고, 방석을 누르면 가서 앉음. WASD, 단축키 1·2·3.
- 방문자 이름은 '형용사 + 자연 낱말'(고요한 산새, 느긋한 솔잎). 캐릭터를 누르면 이름이 잠깐 뜸.
- 위쪽: 나가기, 방('청연당 서버 N', 만석·인원 새로고침·초대 링크), 접속자 수, 소리, 설정, 장면 담기(이미지 저장+링크 공유), 염불 듣기(나에게만 들림).
- 가운데 알림: 안내 / 내 상태("걷는 중·멈추기") / 다른 사람 소식("작은 산새님이 합장으로 인사했어요").
- 아래 행동 바 3개: 합장·절하기(누르면 계속하는 상태, 다시 누르면 멈춤), 염주(전체 화면, 위아래로 넘기며 "이번 바퀴 N알, 모두 N알").
- 설정: 환경음, 염불, 효과음 따로 조절. 공동 예불 매일 05:00·18:00 KST.
- 나가기 화면: "편안히 쉬어 가셨나요 / 다시 쉬고 싶을 때 들러주세요". 탭을 벗어나면 소리 멈춤.
- 기술: three.js + glb 모델, WebSocket 실시간 접속.

## 사용자가 정한 것

- **혼자 들어가는 공간.** 다른 관중은 연출(NPC 으쓱이 + 관중 무리). 실시간 접속 없음.
- **정해진 시간 행사 없음.** 이벤트 버튼으로만.
- **이벤트는 나에게만 보임** (산사 염불처럼). 주변 NPC는 같이 반응해도 됨.
- **등판은 직접 입력만.** 선수명(최대 8자)·등번호(0~99) 자유. 비워 두면 깨끗한 등판.
- 구역 4개, 1루 쪽만: 으쓱이존, 내야, 외야, 하룰라라석(4층 높은 곳).
- 주인공: 단발머리 '○○ 으쓱이'. 형용사는 입장할 때마다 랜덤(화난, 외로운, 기쁜 …), 다시 뽑기 가능.
- 유니폼: 빨강·초록·흰색 중 랜덤으로 입고, 바꿀 수 있음.
- 행동: 응원하기(응원가 + 율동), 화내기(들썩들썩 + 표정 + 대사), 유니폼 흔들기(벗어서 머리 위로 들고 흔들기).
- 야푸먹기 (2026-10-31 확정·구현, `ui/food.js`): 염주 대체. 내 자리 앞 테이블 전체 화면. 배경은 지금 3D 장면을 흐리게 깔고, 관중 함성·응원 비트는 0.7배로 낮춰 계속, 8초마다 가끔 함성이 커지며 태블릿에 '안타!·득점!' 등이 떠요.  
  주문하기 → 크림새우·물회·홈런볼 중 여러 개 골라 한 상에(같은 음식은 한 접시). 누를 때마다 줄어듦: 새우 4번·물회 5번·홈런볼 6번. 빈 그릇은 비닐봉투로 치워지고 '또 주문하기'.  
  기록: 이번 방문 안에서만, 음식별 그릇 수("크림새우 2컵 · 물회 1그릇"). 닫아도 먹던 상은 이번 방문 동안 남고, 다시 입장하면 초기화.  
  테이블 소품: 반응 = 짝짝이(소리)·생맥주(5번 홀짝 → '한 잔 더', 기록 없음). 장식 = 태블릿 중계(점수판·투구), 핸드폰(→ B3에서 잠금화면으로 바뀜, 아래 '야푸먹기 핸드폰 잠금화면'), 입장권(지금 구역·좌석), 기록지, 물티슈·휴지, 비닐봉투.  
  닫은 뒤 으쓱이 먹는 동작은 넣지 않음. 단축키 4, Esc로 닫기.
- 이벤트 4개: 최정 홈런(14번), KKK(29번 김광현 루킹삼진 3번), 벤치클리어링, 꽃돼지 안타(92번이 데굴데굴 굴러 1루까지).
- 응원가: 실제 음원 대신 오리지널 비트. 설정에서 내 음원 파일을 불러올 수 있음(저장 안 됨, 이 화면에서만).
- 작업 방식: 레이어·컴포넌트 단위로 작은 조각씩 만들고, MD 문서로 정보 유실 없이 관리.

## 그라운드 선수 (2026-10-30 추가)

- **공격·수비 모드**로 나눠 배치. 우리 수비 = 우리 팀 9명 수비 + 상대 타자·대기 타자·주루 코치 2명. 우리 공격 = 상대 팀 9명 수비 + 우리 타자·대기 타자·주루 코치 2명. 마지막 선택은 저장됨(기본 수비).
- **우리 팀**: 흰 유니폼 + 빨간 모자(타자는 빨간 헬멧), 빨간 양말. 등판 이름·번호는 **항상 빨간색**.
- **상대 팀**: 회색 유니폼, 짙은 남색 모자·헬멧. 등판 글씨는 남색.
- **평소엔 등판을 비워 둠**(흰 유니폼 + 빨간 모자만). 이벤트나 특정 장면에서만 `setBack(이름, 번호)`로 켜고 `hideBack()`으로 끔.
- 등판 자리를 넉넉히 두려고 몸통을 납작한 타원(가로 1.18배, 앞뒤 0.8배)으로 만들고, 등 쪽 약 110° 너비의 따로 된 등판 면을 둠.
- 홈팀 더그아웃은 1루 쪽(`HOME_SIDE=1`): 우리 대기 타자는 1루 쪽 대기 원.
- 관중석에서 잘 보이도록 실제보다 1.25배 크게(`PLAYER_SCALE`). 우타자 기준.
- 8초마다 투구 한 번: 투수 다리 들기 → 던지기 → 공이 포수 미트로. 야수는 다리 들 때 자세를 낮추고, 타자는 가끔(35%) 헛스윙, 대기 타자는 연습 스윙, 코치는 공이 들어가면 박수. 선수를 누르면 "우리 팀 1루수" 같은 이름표.

## 실제 구장 반영 (2026-10-30 추가)

- 빅보드: 실측 가로 63.398m × 세로 17.962m(약 3.53:1, 2016년 설치)를 1m=1단위로 그대로 씀. 앞면은 홈에서 약 129m, 화면 아래 높이 15m. 양옆·위 이퀄라이저 LED(함성에 맞춰 움직임), 위쪽 물결 지붕 + 다리 주탑·비행기·배 실루엣, 아래 관람동 건물과 "인천 SSG 랜더스필드" 이름 띠, 양옆 3단 광고탑, 오른쪽 뒤 경기장 탑, 가운데 외야 나무숲.
- 그린존: 좌석 안내도 기준 3루 외야 관중석 뒤쪽 잔디 언덕(홈 기준 −46°~−21°, 반지름 123~141m). 돗자리·앉은 관중·그늘막, 폴 쪽 끝 모래놀이장, 좌중간 끝 초가정자, 뒤쪽 나무, 안내판 "그린존 / 돗자리 펴고 쉬어 가요".
- 홈런 현수막: 3루 쪽 외야 관중석(−40° 블록)을 덮는 광고 현수막. 좌석 구역이 아니라, 실제로는 공이 맞으면 상품을 주는 광고판이고 홈런이 자주 떨어지는 자리. 문구는 사용자가 정한 대로 "맘에 드는 맛 / 꽃돼지 한돈"(노란 바탕), 그 아래 직접 그린 야구배트 든 꽃돼지(머리에 꽃). 문구·그림은 사용자 지정이니 임의로 바꾸지 않기. 위치 바꿀 일 없음.
- 바비큐존은 현수막과 별개: 1루 외야 쪽에 있고, 불판에 고기를 구워 먹으며 야구를 보는 좌석 구역. 사진 기준으로 구현: 홈 기준 약 +35.5°~+47°(예전 40° 장식 관중석 자리)에 4줄 × 6칸 계단식 부스. 칸마다 빨강·주황 낮은 벽, 짙은 나무 테이블과 양쪽 벤치, 불판·고기·음료, 민트색 난간, 맨 윗줄 빨간 차양과 이름 띠 "바비큐존 · 구워 먹으며 봐요", 불판마다 피어오르는 연기, 앉은 관중. 보는 풍경이고 걸어 들어가는 구역은 아님.
- 광고판 문구는 실제 브랜드명 대신 지어낸 문구(문학마트, 꿀꿀 BBQ 등).

## 이벤트: 최정 홈런 (2026-10-30 추가)

- 사용자 요청: 14번 유니폼의 최정 타자가 그린존 쪽으로 멋지게 홈런. 빅보드에 큰 파도가 치는 그림이 뜨며 '뿌우우우' 뱃고동. 이어서 파란 바탕(파도 바탕)에 흰 글씨로 큼지막하게 HOME RUN.
- 참고: 사용자가 준 구단 쇼츠 "최정 BEST 홈런 TOP 5"(썸네일 확인) — 방망이를 머리 뒤로 높이 세운 자세, 빨간 헬멧, 흰 홈 유니폼 14번.
- 구현한 흐름(약 25초, 내 화면엔 약 20초): 타자 뒤에서 등판 '최정 14'를 비춤 → 투구 → 다리 들고 딱! → 공을 따라 날아감(흰 점·꼬리) → 3루 외야 너머 그린존(홈 기준 −33°, 129m)에 떨어짐 → 빅보드 정면: 파도 그림(수평선의 배가 증기를 뿜으며 뱃고동, 큰 파도가 솟아 부서짐) → 파란 파도 바탕 + 흰 HOME RUN(테두리 전구) → 높은 곳에서 베이스 도는 모습 → 내 자리로. 타자는 방망이를 툭 던지고 베이스를 돌아 홈에서 대기 타자와 두 손 하이파이브(내 자리로 돌아온 뒤 뒤에서 마무리).
- 수비 모드였으면 장면 동안만 우리 공격으로 바꾸고, 끝나면 원래 모드로 돌려요. 최정 등판은 장면 동안만.
- 주변 으쓱이는 공이 떨어질 때 일어나 환호, 돌아오면 "최정!! 최정!!" 같은 말풍선(`LINES.homer`). 나에게만 보이는 원칙 그대로.
- 소리는 모두 효과음 채널: 딱(방망이), 뱃고동(낮은 소리 두 겹 + 항구 메아리), 파도 소리, 관중 함성 크게.
- 실제 중계 영상·응원가·구단 로고는 넣지 않고 모두 코드로 그린 오리지널.

## 이벤트 배경음 (2026-10-31 추가)

- 사용자가 최정 홈런 전용 배경음으로 구장 육성응원 영상(mp4, 약 30초)을 준비해 옴.
- 실제 응원가 녹음이라 페이지 안에 넣지 않고(아래 '지키는 선'), '내 응원가'처럼 사용자가 직접 고르는 방식으로: 설정 → 이벤트 배경음 → 파일 고르기. 이 기기 브라우저에만 보관.
- 뱃고동은 배경음·함성보다 또렷하게 들려야 함 → 울리는 동안 다른 소리를 낮춤.

## 지키는 선

- 구단 로고·엠블럼·마스코트는 그리지 않음. 색감과 사용자가 정한 등판 문구로 느낌을 냄.
- 실제 응원가 음원·가사는 넣지 않음.
- 실제 광고 그림·브랜드 캐릭터·상표 문구는 따라 그리지 않음. 같은 자리·분위기만 오리지널 그림으로.
- 이전 시도에서 "레퍼런스 UX가 반영 안 됐다"는 피드백이 있었음 → 산사 구성과 톤을 최우선으로 따름. "겨울의 문학"이 아니라 봄날 야구장.

## 실제 응원가 원칙 수정 (2026-10-31)

- 처음 원칙은 '실제 응원가 음원은 넣지 않기'. 사용자가 **직접 찍어 유튜브에 올린 구장 육성응원 녹음**은 본인 녹음이라 넣기로 함 (최정 홈런 배경음). 응원가 곡 자체(멜로디·가사)는 원작자 것이라, 내려 달라는 요청이 오면 그 파일만 빼기.
- 공식 앱 등에서 받은 실제 응원가 음원은 여전히 넣지 않음.

- **등판 이름 글자**가 너무 작다고 해서 유니폼 흔들 때 글자 크기만큼 키움. 몸통 폭을 넘는 긴 이름은 폭에 맞게 줄임(등판 폭이 흔들 때 유니폼보다 좁아서 완전히 같을 수는 없음).
- 작업 방식: 비교용 페이지는 스크린샷을 보고 새로 그리지 말고 **실제 코드(`character.js`·마스코트 파일)를 그대로 가져와서** 그 위에 얹어 보기.

## 외야 세탁소 (작은 패치 U, 2026-11-04)

- 세탁소 = 빈 구역 표를 다 사서 좌석마다 유니폼을 펼쳐, 멀리서 보면 응원하는 선수 등번호처럼 보이게 하는 응원. 사용자가 보낸 사진 속 글씨는 사진 위에 얹은 합성이라 **구장에 글씨를 두는 게 아님**.
- 자리: 꽃돼지한돈 현수막과 걸어 다닐 수 있는 내 활동 구역 사이의 장식 관중석 **네모 두 칸**.
- 번호는 **입장할 때 등에 박은 번호를 따라감**. 한 자리면 왼쪽 칸은 그대로 두고 오른쪽 칸에만, 두 자리면 양쪽에 한 자리씩(번호는 0~99라 세 자리 없음). 번호가 없으면 평소 관중.
- 펼친 유니폼 하나하나가 **진짜 등판**(경기장 구경으로 확대하면 번호가 보임). 멀리서·가까이 안 갈 땐 렌더링을 아끼려 대충 구성해도 됨.
- 등판은 **번호만**(이름은 과해서 제외), **이 구역만 검정 글씨**(다른 으쓱이·선수 등판은 그대로 빨강/남색). 세탁소 유니폼은 따로 만든 코드라 기존 유니폼 코드와 상관없음.
- 이벤트와 연결(최정 홈런 때 14, KKK 때 29)은 **먼저 내 번호로 고정해 완성한 다음** 최정 홈런에만 적용하기로 함. KKK는 카메라가 홈 쪽이라 세탁소가 안 보일 수 있어 이번엔 제외.
- (Claude 제안) 도트 한 칸 = 좌석 3개 × 1줄로 가로 6칸 × 세로 7칸 글자. 줄이 8개뿐이라 숫자가 가로로 납작하게 보이는 건 감안(폰에서 보고 조정).

## 세탁소 고침 (작은 패치 V, 2026-11-04)

- 사용자가 말한 '네모 두 개' = 현수막 바로 옆 **한 블록의 가운데 통로 좌우 두 구역**. 숫자는 이 두 구역에 **하나씩**(왼쪽 십의 자리, 오른쪽 일의 자리). 한 자리면 오른쪽 구역에만. 옆 블록은 건드리지 않음.
- 세탁소 유니폼은 **흔드는 유니폼의 숫자 글꼴·크기를 따라감**(모양도 같은 티셔츠). 글씨만 검정.
- '외야 걷는 구역을 침범했다'는 사용자의 착각이었음(걷는 외야는 1루 쪽 반대편 블록). 무시하기로 함.

## 내야 연장 · 폴 모서리 장식 블록 (작은 패치 W, 2026-11-04)

- 목표는 완벽한 3D 재현이 아니라 **문학의 포인트를 그럴듯하게**. 관중석 블록을 옮기거나 외야 전체를 곡면 스탠드로 바꾸지 않고, 끊긴 곳만 장식 블록으로 채우기로 함(외야 블록에 세탁소·현수막·바비큐존·여난부두 불빛·밤 어둡기·걷기 좌표가 얽혀 있어서 대공사는 위험). 곡면화는 나중에 걷지 않는 장식 구간부터 해도 이번 블록은 그대로 쓸 수 있음.
- **1·3루 좌우 대칭**(좌석 안내도가 대칭). 내야석은 장식 블록을 덧붙여 더 길게, 폴 바깥 모서리에도 장식 블록 한 칸.
- **쐐기 모양으로 비는 곳은 꼭 관중으로 채움**(허해 보이지 않게). 여난부두 불빛도 거기까지 같이 켜짐.
- **외야 높이는 안 올리고 담장도 안 낮춤**: 높이를 건드리면 최정 홈런·여난부두·걷는 외야·세탁소가 연쇄로 영향을 받고, 담장은 지금도 실제보다 낮은 편이라 더 낮추면 야구장 감성이 줄어서.
- **불펜은 이번엔 뺌**: 실제 불펜은 담장 아래 길쭉한(약 18m) 구덩이인데 지금 넣을 수 있는 자리는 4×9m라 선수 모델이 장난감 집에 들어간 것처럼 보임. 제대로 하려면 모서리 구조와 3루 꽃돼지 현수막 블록까지 뜯어야 해서 보류(문 열림·불펜 투수/포수 아이디어는 보관).
- **홈런커플존도 이번엔 뺌**: 높이 1.2m 데크 위 관객이 3.1m 담장을 정면으로 봐서 어색. 담장·관중석 높이를 못 바꾸니 나중에 관객 방향·소품을 따로 상의.

## 라커룸 (작은 패치 Y, 2026-11-05)

- 불펜장 '내 라커' 첫 화면을 **라커룸**으로. 위쪽 제목도 '라커룸'. 실제 선수 라커룸(빨간 틀·번호판 띠·열린 칸)을 닮게.
- **구도(세 번 고침)**: 처음엔 칸을 네모로 나눈 납작한 그림 → 입체감이 없고 물건 크기도 안 맞아 못생겨 보임 → **내 라커 앞에 서서 보되, 라커 안이 뒷벽·옆벽·바닥·천장으로 구분되는 입체 상자**로. 네 칸으로 단순 분할하지 않기. 소실점 하나로 모든 칸이 안쪽으로 깊어짐.
- 배치: **왼쪽 = 긴 내 라커(유니폼만)**, **오른쪽 위 = 열린 찬장(코르크 + 티켓 두 장이 주인공)**, **오른쪽 아래 = 선반 3~4칸(맨 위에 기념구 + 금 글러브)**. 의자는 없앰, 가방도 이번엔 뺌(나중에 직관 짐싸기와 이을 때 자리 찾기).

- **일정표는 아주 작고 흐리게**(티켓보다 중요해 보여서 오해를 일으킴). 티켓 개수는 변동 없이 늘 두 장.
- 유니폼은 **두 벌**: 앞면(L) + 뒤집은 등판(입장 준비의 이름·번호). 번호를 안 정했으면 **'V6'**(번호판·등판). 이름이 없으면 번호판엔 번호만.
- **금 글러브 숫자 = 퍼펙트 횟수**(143개를 12개씩 나눠 한 판을 전부 나이스 캐치할 때마다 글러브 하나를 모으고, 최대 12). 글러브에 1~12가 박히고 13번째부터는 12. 퍼펙트가 한 번도 없으면 글러브는 안 보임. (처음에 '늘 12'로 잘못 이해했다가 바로잡음)
- 윗띠: 라커 번호판 띠(빨강)를 오른쪽 끝까지 이어서 실제 라커룸 사진 느낌을 냄.
- 눌러지는 곳은 들어갔을 때 ✦가 **두 번 반짝**(처음 한 번만). 자리는 유니폼 소매·티켓 모서리·유리 케이스·글러브. 누르기는 로비와 같게(한 번 → 이름표, 한 번 더 → 열림).
- 소매 끝 빨간 줄은 소매 끝 모서리를 따라 붙어야 함(떠 있으면 안 됨).
- 야구장 입장 준비에서 **유니폼 색을 저장하지 않아서** 라커룸 유니폼은 흰색 고정(필요하면 색 저장 한 줄을 야구장 쪽에 더하기).
- 작업 방식: 아티팩트 시안으로 먼저 보고 확정한 뒤에 깃허브용 묶음을 만듦.

## 팀 이름 글자 바꾸기 (작은 패치 Z, 2026-11-06)

## 직관 짐싸기 — 불펜장 미니게임 4 (묶음 AA, 2026-11-07)

- 불펜장 네 번째 게임. 다른 세 게임(등번호 매치·홈런볼·티켓팅)이 클릭 기반이라 이건 **끌어서 가방에 담기**(눌러도 담김, 담긴 걸 다시 누르면 빠짐). 허겁지겁 챙기는 느낌의 **타임어택**, 판정은 '야구보러 출발!'을 누를 때 한 번에.
- **규칙 추론 게임**: 시작 전 조건 화면(5·4·3·2·1) 뒤에는 조건을 **다시 볼 수 없음**(외워서 챙기기). 구장 이름 대신 홈경기/원정경기로만 보여 주고, 티켓·야푸에 구단과 매핑되는 힌트 글자는 모두 뺌. 규칙 설명은 별도 튜토리얼 없이 **실패·실책 대사**로만.
- 화면: 한 화면 4분할 → **3단계(책상 → 열린 옷장 → 야푸 생각풍선)**로 변경. 음식은 경기장에서 먹는 거라 가방에 안 들어감. 티켓은 정답 포함 4장만. 물건 그림은 3D 으쓱이와 별개로 이 2D 게임용으로 따로(ChatGPT).
- 날씨는 낮밤·계절 대신 **해가 쨍(선글라스) / 구름 낌(둘 다 X) / 가랑비(우비)**, 기온은 달 기준 더움·쌀쌀. 이벤트는 한 경기에 하나, 홈 이벤트는 그린데이·인천상륙데이를 높이고 레드데이를 낮춤(유니폼 골고루). 창원 음식은 아구찜.
- 등급: 실패 / 성공(소소한 실수 = **실책**, 일기에 '오늘의 실책') / **무실책**(성공 도장 옆 초록 '무실책 ✓'). 퍼펙트 이름은 '출루왕' → '퍼펙트직관러' → **'퍼펙트 n회'**(한 달 묶음 전부 무실책, 홈런볼 금 글러브처럼 0이면 숨김). V6 도장 같은 시즌 전체 숨은 엔딩은 하지 않음(144경기 중 65승뿐이라 승리와 무관한 짐싸기 완벽도에 과한 의미 금지). 시즌 마지막 칭호 없이 모으는 것이 끝.
- **금색 원칙 폐기**(전엔 퍼펙트에만): '쓸 때 쓰자' → 무실책 칸은 구석의 **작은 금색 별**, 그 달의 👑도 금색. 달 총평 문구는 **없앰**('x/xx 경기 클리어' 문구도 화면이 비어 보여 삭제).
- **으쓱이 다이어리**(이름은 '시즌 다이어리'에서 변경): 일기 + 달력 6묶음(3~4월/5/6/7/8/9~10월). 진짜 일정·결과(KBO 공식)와 게임 요소(날씨·기온·이벤트)를 한눈에 구분되게: 경기 팝업은 **네모 안에 진짜 정보(상대·홈/원정·점수판), 그 아래 게임 조건 칩**만 — 설명 문구는 모두 뺌(설명충 금지). 안 깬 경기는 점수 '? : ?'·조건 칩 '???'·구장 이름 숨김(스포 방지). 직관 메모는 없앰.
- 승·무·패와 승률은 **내가 깬 경기만** 세서 깰수록 바뀜(승률 = 승 ÷ (승 + 패), 두 자리). 달력은 ChatGPT가 그린 빈 달력 그림 위에 얹음(리본=달 이름, 리본 아래=승무패, 둥근 칸=승률). 5주짜리 달은 6번째 줄이 빈 칸으로 남음.
- **올스타 브레이크(7/10~7/15)**: 달력에 따로 표시, 누르면 홈런볼 모으기의 올스타 컷신 그림(배경·춤추는 다섯 명 그대로)이 이 게임에 맞는 **테이프 붙인 폴라로이드 프레임**으로 뜸(계속 춤춤).
