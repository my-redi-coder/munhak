# 직관 짐싸기 (불펜장 미니게임 4) — 기획 확정본 (2026-11-07)

2026 정규시즌 144경기 중 한 경기를 골라, **그날의 조건(상대·홈/원정·날씨·기온·이벤트)**에 맞게 직관가방을 싸는 타임어택. 결과는 **으쓱이 다이어리**(일기 + 달력)에 쌓여요.
코드: `minigames/packing.html` + `minigames/packing/` (층 구조는 `docs/ARCHITECTURE.md`의 '불펜장').

## 1. 한 판의 흐름
1. 열면 **랜덤 경기**(아직 안 깬 경기 우선)의 **조건 화면**(날짜·상대·홈경기/원정경기·날씨·기온·이벤트)이 크게 뜨고 **5·4·3·2·1 카운트다운**. 게임이 시작되면 조건은 **다시 볼 수 없어요**(외워서 챙기기).
2. 제한 시간 안에 3단계: **책상**(티켓 4장 중 정답 + 교통카드/기차표) → **열린 옷장**(유니폼 4벌 + 소품 4개) → **야푸**(가서 먹을 음식 고르기, 가방엔 안 들어감).
3. 물건은 **끌어서** 투명 직관가방에 담아요(톡 눌러도 담기고, 담긴 물건을 다시 톡 누르면 빠져요).
4. **'야구보러 출발!'**을 누르면 한 번에 채점. 시간이 다 되면 실패.
- 제한 시간: 깬 경기가 **5개 미만이면 45초 → 45개 미만이면 30초 → 그다음(나머지 99경기)은 20초**(`play.js`의 `pkLimit`).
- 글자: 이 게임은 **SSC·란다스**(야구장 안과 같은 표기: 란다스무디, '란다스네 명물이 아니었다', 달력 점수판 'SSC')로 써요. 기존 미니게임(홈런볼 모으기·등번호 매치·티켓팅 War)은 진짜 기록이라 **SSG·랜더스 그대로**예요.

## 2. 정답 규칙 (`rules.js`의 `expected`)
| 칸 | 정답 |
|---|---|
| 교통 | 홈 · 수도권 원정(두산·LG·KT·키움) = 교통카드 / 지방 원정(삼성·롯데·한화·NC·KIA) = 기차표 |
| 티켓 | 상대 구단 티켓 (4장 중) |
| 유니폼 | 이벤트가 있으면 이벤트 색(레드데이=빨강 · 그린데이=초록 · 인천상륙데이=크림). 없으면 **원정=빨강, 홈 금·토=초록, 홈 일=크림, 홈 화~목=흰빨** |
| 날씨 | **해가 쨍 = 선글라스 / 구름 낌 = 둘 다 안 챙김 / 가랑비 = 우비.** 고척돔은 날씨와 상관없이 둘 다 필요 없음 |
| 기온 | 3·4·10월 쌀쌀, 7·8월 더움, 5·6·9월은 경기마다 랜덤. 더움 = 손선풍기, 쌀쌀 = 바람막이(반대로 챙기면 실책) |
| 음식 | 구장별 명물: 문학 란다스무디·크림새우 / 고척 크림새우 / 대전 빵봉지 / 잠실 김말국 / 수원 뽀용만두 / 사직 돼지국밥 / 대구 납작만두 / 광주 육전 / 창원 아구찜 |
- **이벤트**(경기의 약 28%, 한 경기에 하나): 홈경기 = 레드데이 · 그린데이 · 인천상륙데이 · 입맛 없음 · 곰산 팬 친구 동행 / 원정 = 입맛 없음 · 곰산 팬 친구 동행. 홈 이벤트 비율은 그린·인천 높고 레드 낮게(가중치 0.5 : 2 : 2 : 1 : 1) — 유니폼을 골고루 입도록.
  입맛 없음 = 음식 필요 없음 / 곰산 팬 친구 동행 = 음식 전부 필요.
- 날씨·기온·이벤트는 **경기마다 정해진 랜덤**(실제 날씨 아님). 일정·승패·점수는 **KBO 공식 기록**.

## 3. 결과 등급
| 등급 | 조건 | 일기·달력 |
|---|---|---|
| 실패 | 교통·티켓이 틀림, 또는 시간 초과 | 기록 안 남음(다시 도전) |
| 성공 | 소소한 실수(유니폼·소품·음식)가 있음 | **파란 '성공' 도장**, 일기 맨 아래 칸 '오늘의 실책: 우비 1개' |
| 성공 + 무실책 | 실수 0개 | '성공' 도장 + 초록 **'무실책 ✓'** 도장을 옆에 따로 · 달력 칸 구석에 **작은 금색 별** |
- 더 잘한 기록만 남아요(다시 해서 나빠지면 원래 기록 유지).
- **퍼펙트 n회**: 한 달 묶음의 모든 경기를 무실책으로 깨면 1회(홈런볼 금 글러브와 같은 방식, 0이면 배지 숨김). 마지막 경기를 깬 일기 화면에 반짝이는 축하 문구.

## 4. 일기 (`diary-lines.js`)
날짜·날씨 → 도착 → 티켓 → 소소한 실수 한 줄씩(실책은 빨강) → 마무리 → 맨 아래 칸에 '오늘의 실책'. **교통·티켓을 틀리면 거기서 끝**(규칙 설명은 실패 대사로만).
- **곰산전**(홈·원정 모두): 실책이 아닌 웃긴 문장 — 문학: 란다스무디 "이미 솔드아웃" · 크림새우 "줄이 너무 길어서" / 잠실: 김말국 "곰산 팬들이 다 털어가서 솔드아웃".
- **곰산 팬 친구 동행** 날 음식을 빼먹으면 "곰산 팬 친구가 ○○이 먹고 싶다고 투덜투덜거렸다.... 여긴 ○○인데..."(그 구장에서 안 파는 음식만, 여러 줄이 줄줄이 나오는 게 웃겨서 그대로). 그 구장 음식은 평소 문장.
- 필요 없는 음식은 "○○은 △△네 명물이 아니었다."(음식은 가서 먹는 것이라 '챙겼다'는 말 안 씀).

## 5. 으쓱이 다이어리 (달력, `calendar.js`)
- 달 탭 6묶음: 3~4월 / 5월 / 6월 / 7월 / 8월 / 9~10월. ChatGPT로 그린 빈 달력 그림(`img/calendar-bg.webp`, 1024×1536) 위에 칸을 얹음(리본=달 이름, 리본 아래=승무패, 둥근 칸=승률, 요일 칸, 7×6칸).
- **승무패·승률은 내가 깬 경기만** 세어서 깰수록 바뀜(승률 = 승 ÷ (승 + 패)). 달 총평 문구·'x/xx 클리어' 문구는 없음.
- 칸: 팀 이름 띠(@=원정) · 깬 경기는 큰 승/패/무 도장. **7/10~7/15 올스타 브레이크** 칸은 누르면 홈런볼의 올스타 춤추는 선수 그림이 폴라로이드 프레임에 떠요(`break.js`).
- 경기 팝업: 네모 안에 상대·홈/원정·점수판 + 아래에 게임 조건 칩 + 내 일기 + 맨 끝 '다시 짐싸기'. **안 깬 경기는 점수 '? : ?', 조건 칩 '???', 구장 이름 숨김**(스포 방지).
- 라커룸에서 `packing.html#diary`로 바로 열 수 있어요.
