# 문학기념관 — memorial.html

로비의 **문학기념관 문**으로 들어오는 3D 전시관이에요. 팬들이 알아보는 짤을 액자에 걸어 둬요. (2026-11-17, 패치 `AQ-memorial`에서 열림. 시안은 아티팩트 '문학기념관 2026 (시안 3)'이고 그 모양을 그대로 옮겼어요)

## 공간

- 입구에서 **오늘의 포토**(전체 짤 중 하나, 입장 때 정해지고 지난번과 다른 짤) 앞에 톡 떨어져요.
- 왼쪽 = **최광야구**(상설전시, 코드 `CK-01…`), 오른쪽 = **A존**(2026년 짤, `A-01…`) → **B존**(그 이전 짤, `B-01…`). C·D존은 안 열어요(`MH.OPEN`에 넣으면 열릴 준비).
- 통로는 야구장 콩코스처럼 둥글고, 벽은 선수통로 톤(흰 벽·빨강), 바닥은 밝은 회색 타일. 으쓱이는 야구장과 똑같이 걸어요(바닥 누르기·‹ › 길게 누르기·키보드).
- 아래 칩으로 최광야구·입구·A·B를 빨리 오가요. 짤을 누르면 크게 보기(제목·코드·저장). 오늘의 포토를 누르면 '걸린 자리로 가기'도 떠요.
- 액자 위 벽 글씨 = 제목 + 빨간 줄 + 코드(·2026). **태그·사람 이름은 화면에 안 나와요**(내부 관리용). 과거(`-`) 짤은 연도 글자를 안 써요.
- 비율이 16:9가 아닌 사진은 좌우를 흰색으로 채워요.

## 으쓱이 꾸미기 (처음 한 번만)

로비에서 바로 오면 경기장 '입장 준비'를 안 거쳐 유니폼·등판이 비어요. 그래서 **처음 한 번만** 꾸미기 창(`js/memorial/dress.js`)이 떠요: 유니폼 색·모자·등판 이름·번호.

- 뜨는 조건: `munhak:dressed`가 없고 등판 이름·번호도 저장돼 있지 않을 때. 경기장에서 이미 꾸민 사람은 안 떠요.
- '전시관 들어가기'를 누르면 저장하고 다시 안 떠요. 기념관 안에는 다시 바꾸는 버튼이 없어요(경기장 입장 준비는 지금처럼 매번 떠서 바꿀 수 있어요).
- 유니폼 색도 이제 **저장**돼요(`munhak:uni`) — 경기장·기념관에서 같은 모습. 저장된 색이 없으면 예전처럼 랜덤. 야구장의 `js/core/config.js`(ME.uni)·`js/ui/setup.js`(색 고를 때·입장할 때 저장, 입장하면 `dressed`)를 이 패치에서 고쳤어요.

## 짤 올리고 걸기 (흐름)

1. 아티팩트 **'문학기념관 짤 올리기'**(폰에서): 사진 최대 10장 → 제목(12자 이내) · 구역(a / b / 최광야구) · 태그(내부용) · 사람 이름(여럿 가능, 내부용). 연도는 구역을 따라 자동(a=2026, b=`-`, 최광야구=2026).
2. Claude에게 **"짤 반영해줘"** — 올라온 짤을 받아 `memorial/photos/`에 파일로, `memorial/photos.json`에 한 줄씩 넣고 깃허브에 올려요(기존 줄은 그대로).
3. 구역 길이·통로 길이·빈 액자 수는 **짤 개수에 맞춰 자동**으로 늘어나요(코드 수정 없음).

## photos.json

```json
{ "id": "p-…", "file": "photos/cmon.jpg", "title": "C'mon", "zone": "K", "year": "2026", "tags": ["최광야구"], "people": ["안성현"], "comment": "" }
```

- `zone`: `K`(최광야구) · `A` · `B`. 위에서부터 차례로 걸려요(구역별로 따로 셈). 순서를 바꾸고 싶으면 줄 위치를 옮기면 돼요.
- `title` 12자 이내(넘으면 잘림), `comment`는 선택(액자 아래 벽에 작은 글씨).
- `tags`·`people`는 아직 화면에서 안 쓰고 **사람 특별전·태그 특별전**용으로 모아 둬요.
- 이미지는 16:9 ~1600×900 JPEG를 권장(가벼워야 로딩이 빨라요).

## 고치는 곳

- **구역 열기(C·D 등)**: `MH.ZONES`·`MH.OPEN`·`layout.js`의 구역 목록(`['K','A','B']`)에 더해요. 메뉴 칩·벽 글자는 `OPEN`을 따라가요.
- **걸리는 자리**: 바깥 벽과 안쪽 벽에 엇갈려 번갈아 걸려요(한 벽 안에서는 `gap` 간격). 최광야구는 안쪽 벽의 빨간 큰 글씨 벽(입구에서 11~21m)을 피해 그 뒤부터 안쪽 벽을 써요. 자리 계산은 `js/memorial/layout.js`, 칸마다 `wall`(in=바깥, out=안쪽). 입구 홀·'오늘의 포토'는 그대로 바깥 벽.
- **액자 크기·간격·천장 높이**: `js/memorial/config.js`의 `HALL`.
- **벽 문구**: `graphics.js`. 노랑·금색은 쓰지 않아요(시안 3 피드백).
- **로비 문**: `js/lobby/config.js`의 `museumOpen`·`hotspots.museum`(이름표 '문학기념관 / 짤 전시관').

## 지키는 선·알아둘 것

- 통로 길이는 짤 약 60장까지 무난해요. 그보다 길어지면 반지름이 커져(`layout.js`) 둥글기가 완만해져요.
- 벽 글씨 글꼴(Barlow Condensed·Noto Sans KR)은 구글 글꼴에서 받아요(시안 그대로). 못 받으면 비슷한 기본 글꼴로 보여요.
- `memorial/photos.json`이 없거나 못 받으면 빈 액자만 있는 기념관으로 열려요.
