## 그라운드 선수 — 완료 (2026-10-30)

- 선수 모델 `entities/player.js`: `Ballplayer({team:'home'|'away', role, gear})`. role은 P·C·1B·2B·SS·3B·LF·CF·RF·B(타자)·D(대기 타자)·K(코치). gear `'bat'`=헬멧+방망이, `'none'`=글러브 없음, 포수는 마스크·가슴 보호대·정강이 보호대·큰 미트 자동

- 자세는 `bpPose()` 값(몸통 tX·tY, 다리 thA·knA·spA, 팔 uaX·faX…)을 `p.apply(P,k,dt)`로 적용. 발이 땅에 닿도록 몸 높이 자동 계산

- 화면 확인은 헤드리스 브라우저(소프트웨어 렌더링)에서만 했어요. 실제 휴대폰 성능은 써 보며 확인 필요.

- 공격·수비를 바꾸면 선수가 바로 바뀌어요(뛰어 들어오는 연출 없음). 주자·심판은 아직 없음.
- 최정 홈런: 헤드리스에선 프레임이 느려 공 비행·스윙 타이밍은 띄엄띄엄만 봤어요. 실제 기기에서 스윙 모양·공 보이는 정도 확인 필요.
- 최정 홈런: 소리가 꺼져 있으면 뱃고동·딱 소리 없이 화면만 나와요(별도 안내 없음).
