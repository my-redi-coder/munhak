SSG 팬 레디코더가 만든 오리지널 캐릭터예요. 공식 구단 캐릭터와는 상관없어요.
응원단상(묶음 C, 2026-11-01)에 처음 세웠고, 앞으로 다른 곳에서도 계속 쓸 캐릭터예요.
다른 채팅에서 레디·배리를 다시 만들거나 쓸 때는 **이 문서를 기준**으로 해요.

## 레디: 진돗개

| 부분 | 규칙 |
|---|---|
| 털 | 진회색 `#3a3b40` (검정 아님. 3D에서 형태가 살고 눈썹·코와 대비되게) |
| 귀 | 크고 뾰족한 세모 두 개, 위쪽 바깥으로 벌어짐. 안쪽은 조금 밝은 회색 `#5a5b63` |
| 눈 | 흰자 있는 동그란 눈 + 까만 눈동자 |
| 눈썹 | 까맣고(`#111114`) 굵은 아치. 몸보다 확실히 진하게 |
| 코 | 가로로 넓은 까만 코, 얼굴 앞으로 튀어나옴 |
| 입 | 통통한 윗입술 두 덩이(가운데 홈), 아래 테두리를 따라 바깥으로 올라가는 **웃는 입선**, 그 사이로 **작은 분홍 혀**. 윗입술에 수염 점 |
| 팔·발 | 진회색 캡슐 팔, 다리 없이 납작한 타원 발 두 개 |
| 꼬리 | 없음 |
| 키 | 1.35 (귀 끝까지) |

## 배리: 이빨(어금니)

| 부분 | 규칙 |
|---|---|
| 몸 | 위가 두 봉우리인 어금니. 납작하지 않고 앞뒤로 **통통하게 둥근** 모양 |
| 색 | 미색 `#f5efe0` + 베이지 윤곽선 `#d6ccb0` + 왼쪽 위 흰 하이라이트 곡선 |
| 눈 | 까만 점 두 개, **안광 없음** |
| 볼 | 분홍 볼터치 `#e8b4b4`, **늘 있음(포즈 중에도)** |
| 입 | **없음**. 표정은 늘 무표정 |
| 다리 | 뿌리 두 개(아래가 뾰족한 작은 물방울) |
| 팔 | 미색 짧은 캡슐 |
| 크기 | 레디와 몸통 크기가 같게 — 설계 키 1.35 × `size` 0.86 ≈ 1.16 |

## 둘 다

- 응원봉 없음.
- 유니폼: 내 으쓱이 색(빨강·초록·흰색)을 따라 입음. V넥 + 가슴 가로줄 하나. 빨강·초록은 흰 줄·흰 글씨, 흰 유니폼은 빨간 줄·빨간 글씨.
- 등판: 위에 이름(레디 / 배리), 등번호 자리에 크게 **V6**.
- 시그니처 포즈: 팔을 위로 대각선 V로 벌림(0.3초) → 그 자세로 몸 전체가 위아래로 덜덜덜(1.5초, 레디는 귀도 달달) → 팔 내리고 원래 동작(0.4초).

## 코드에서 쓰는 법

필요한 파일: three.js(r128) → `js/entities/mascot-kit.js` → `mascot-redi.js` → `mascot-barry.js`. 야구장 다른 코드는 필요 없어요.

```js
var redi = makeRedi({ uni: 'red', detail: 'full' });   // detail: 'full' 가까이 보는 곳, 'lite' 멀리 보이는 곳
var barry = makeBarry({ uni: 'red', detail: 'full', scale: 1 });
scene.add(redi.root); scene.add(barry.root);           // 발바닥(뿌리 끝)이 y=0, 정면이 +z
// 매 프레임
redi.update(dt, beat); barry.update(dt, beat);         // beat를 안 주면 128BPM으로 혼자 셈
redi.setUniform('white');                              // 유니폼 바꾸기
redi.pose('cheer');                                    // 'cheer' 율동 / 'idle' 서 있기
redi.signature();                                      // 시그니처 포즈
```

- 누르기: `redi.meshes`를 레이캐스트 대상에 넣고, 맞은 물체의 `userData.mascot`이 그 캐릭터예요.
- 생김새 숫자(색·비율·위치): `REDI_DESIGN`·`BARRY_DESIGN` (각 파일 맨 위). 포즈 시간: `MASCOT_SIG`, 떨림 세기·V 각도: `Mascot`의 `shakeAmp`·`vUp`.
- 응원단상에서의 자리·랜덤 포즈 간격: `js/game/mascots.js`의 `MASCOT_CFG`.
- 미리보기: claude.ai 아티팩트 '레디·배리 3D 미리보기 (리뷰용)'.
