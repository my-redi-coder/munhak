## 작은 패치 J: 경기장 구경 — 보는 곳 옮기기 — 완료 (2026-11-03, `munhak_2026-11-03_J-sightsee-pan`)

- 문제: 경기장 구경에서 돌리기·확대는 되지만 카메라가 늘 야구장 한가운데(`SS.T`)만 봐서, 꽃돼지한돈 포스터 같은 구석을 확대할 수 없었음
- 고침(`js/game/sightsee.js`, `js/game/input.js`):
  - 두 손가락으로 확대하면서 같이 끌면 보는 중심이 옮겨감(`ssPan`, 지도 앱처럼 손가락 따라옴). PC는 오른쪽 버튼 드래그 또는 Shift+드래그
  - 두 번 톡 누르면 누른 곳(포스터·관중석 등 실제 물체)으로 중심 이동 + 약 0.55배 가까이(`ssTap` → `ssFocus`). 하늘·구름·빛은 건너뛰고, 아무것도 없으면 땅(y=0) 위치
  - 중심이 처음 자리에서 멀어지면 위쪽 오른쪽에 '가운데로' 버튼(JS로 만듦, `ssBtn`/`ssHome`). 구경을 다시 시작하면 늘 가운데·기본 거리에서 시작
  - 중심 한계선 `SS.LIM`(가로 ±150, 세로 −160~50, 높이 0~60), 가장 가까이 `SS.MIN` 30 → 10
- 확인: 문법 검사 + 이동 방향·한계선 계산 시험. 폰에서 볼 것: 두 손가락 이동 손맛(속도), 더블탭이 포스터에 맞는지, '가운데로' 버튼 위치, 아주 가까이 갔을 때 시야
